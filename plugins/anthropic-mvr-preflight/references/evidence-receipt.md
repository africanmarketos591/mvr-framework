# MVR Evidence Receipt

Use this compact structure when presenting a completed public preflight:

- Decision under review
- Entity and target geography
- Evidence received
- Verification status and source families
- Evidence gaps
- Safe inferences
- Unsafe or unsupported inferences
- Maximum safe action available now
- Next three evidence unlocks
- Human-review or licensed route, if applicable

Preserve `not_a_verdict`, abstention, and human-review language exactly. Never translate a route-to-scoring result into a readiness verdict.
