## Receiver-side enforcement

An independent Python receiver ran on a fresh GitHub-hosted Ubuntu machine. It validated the live lab issuer’s signatures and current revocation feed before writing to its own SQLite ledger. All 14 HTTP scenarios passed, including a valid single write, concurrent delivery, replay, expiry, and recovery after a crash. Restarting the receiver preserved the single-write guarantee. [GitHub Actions job](https://github.com/africanmarketos591/mvr-framework/actions/runs/43637050446/job/132579385875)

The test obtained a signed commit, revoked its capability before delivery, and submitted the commit inside its validity window. The receiver refused it. A separate read-only SQLite connection found **1 positive-control row**, **0 rows for the revoked commit**, and **6 total drafts both before and after delivery**. GitHub operated the runner and AMOS supplied the workflow and lab issuer. A customer-operated deployment has yet to be observed.
