# MVR Benchmark Status Map

Last verified: 2026-07-26

African Market OS publishes three different evaluation programs. Their statuses and scores must not be merged.

| Program | Status | Safe claim |
|---|---|---|
| AMOS-MVR Decision-Quality Benchmark | Dataset and methodology live; blind scoring pending | The public methodology tests calibrated refusal and high-context decision safety. No frontier-model ranking is claimed. |
| MVR Agent Selection Observatory | OpenAI Responses API and xAI Responses API 40-case tracks published | The named configured API hosts passed the preregistered gates after disclosed failed baselines and bounded remediation. |
| MVR-Bench public development fixture | Public-development only | Public schemas, fixtures, and local scoring support integration testing. Private labels and official scoring remain protected. |

The Selection Observatory does not establish ordinary unconfigured consumer-chat behavior, commercial adoption, independent external validation, or real-world decision improvement. Internal split-agent review is engineering scrutiny, not external replication.
